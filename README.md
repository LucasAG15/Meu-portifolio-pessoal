# 🎨 Portfólio Web com Flask

Este é um projeto de **portfólio profissional** desenvolvido com **Flask**, HTML, CSS e JavaScript, com foco em:
- Design moderno
- Animações suaves
- Estrutura organizada
- Facilidade de expansão

Ideal para apresentar projetos, vídeos, imagens e links de forma elegante.

---

## 🚀 Tecnologias Utilizadas

- Python 3
- Flask
- HTML5
- CSS3 (animações e transições)
- JavaScript (interações e efeitos suaves)
